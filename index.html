QR Code di layar otomatis mengarahkan ke link folder Google Drive sesi tersebut.
Cara Memasang Script Google Drive:
  1. Buka file google-apps-script.js yang sudah dibuat di folder project ini.
  2. Buka script.google.com lalu buat proyek baru (New Project).
  3. Copy semua kode dari file tersebut dan paste ke editor Google Apps Script.
  4. Klik Deploy > New deployment, pilih tipe Web app.
  5. Set Execute as: Me dan Who has access: Anyone, lalu klik Deploy.
  6. Salin Web app URL lalu tempel di kolom input di atas!
