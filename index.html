PERTANYAAN UMUM

Frequently Asked Questions (FAQ)

Apakah software ini membutuhkan koneksi internet?

Software Eazy Fotobooth dapat berjalan secara offline untuk pengambilan foto, render photo strip, dan video motion MP4. Koneksi internet hanya dibutuhkan jika Anda mengaktifkan fitur auto-sync Google Drive dan akses galeri online.

Kamera apa saja yang didukung?

Eazy Fotobooth mendukung Webcam USB (seperti Logitech C920/Brio), kamera bawaan laptop/iPad/Android, hingga kamera DSLR/Mirrorless melalui USB Capture Card (Cam Link).

Bagaimana cara memasukkan frame desain kustom?

Anda dapat mengunggah file PNG transparan atau JPG dengan area green screen di menu "Studio Frame Custom" pada Dashboard Admin. Sistem AI akan otomatis mendeteksi kotak slot foto untuk Anda.

Bagaimana cara kerja backup ke Google Drive?

Kami menyediakan script Google Apps Script gratis yang dapat Anda pasang di akun Google Anda sendiri. Script ini akan otomatis membuat folder event baru dan menyimpan foto strip, GIF, dan pose satuan secara instan.
